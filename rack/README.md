# 10インチラック用 キーストーン パッチパネル（10口・1U）

3Dプリンターで作る、10インチ（254mm幅）サーバーラック用のパッチパネルです。
市販のキーストーンカプラー／キーストーンジャックをはめ込んで使います。

## 印刷するファイル（`stl/` フォルダ）

| ファイル | 内容 | いつ使う |
|---|---|---|
| `keystone_fit_test.stl` | 穴の大きさの試し刷り（3種類） | **最初に必ず**。手持ちのカプラーで合う穴を確かめる |
| `patch_panel_10port_1U.stl` | パネル本体（1枚もの・254mm） | 造形サイズが 256mm 以上のプリンター（Bambu Lab A1 / P1S / X1 など） |
| `patch_panel_10port_1U_left.stl` / `_right.stl` | 本体を左右に2分割 | 造形サイズが小さいプリンター（Ender-3 など 220mm） |
| `splice_bar_x2.stl` | 2分割版をつなぐ裏当てバー | 2分割版のとき **2個** 印刷。M3ネジ×4本とナットで留める |

## 手順

1. `keystone_fit_test.stl` を印刷し、カプラーをはめてみる。
   穴の上の小さな凹みの数で大きさが分かる（1個=小、2個=標準、3個=大）。
2. 標準（2個）がちょうど良ければ、そのまま本体を印刷。
   きつい・ゆるい場合は、`patch_panel.py` の `KEY_W`（幅）と `KEY_H`（高さ）を
   合った穴に合わせて ±0.3 し、`python rack/patch_panel.py` で作り直す。
3. 本体を印刷して、ラックに M6 ネジで取り付ける（取付穴は横長で、多少の位置ずれは吸収）。

## 印刷設定の目安

- 向き: 正面（平らな面）を下にする。サポート不要。
- 素材: PETG がおすすめ（PLA でも可。ラック内が熱くなるなら PETG / ASA）。
- 積層 0.2mm、壁 3〜4周、インフィル 30% 以上。

## 主な寸法

- パネル: 幅 254 × 高さ 43.6 × 奥行 12mm（正面板 2mm ＋ 上下の補強リブ）
- 取付穴: 中心間隔 236.5mm、直径 6.5mm（横に 4mm 長穴）
- ポート: 10口、間隔 19.5mm、穴 14.9 × 16.6mm
