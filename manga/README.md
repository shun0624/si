# マンガ制作セット（ComfyUI）

ネーム（ラフでコマ割りしたページ）を描き、コマごとにAIでキャラを描いて、ページに戻すためのセットです。
`setup.bat` をダブルクリックすると、必要なものがまとめて入ります。

```
① ネームを描く（CLIP STUDIO など）
        ↓
② コマ切り出し … ネーム画像をドラッグ＆ドロップすると、コマごとの画像ができる
        ↓
③ ComfyUI … コマのラフ＋キャラのLoRA＋指示文で、候補が4枚できる
        ↓
④ コマはめ込み … 選んだ画像をページに戻して仮組みする
        ↓
⑤ CLIP STUDIO でトーン・フキダシ・セリフを入れて仕上げ
```

## 入るもの

| 種類 | 内容 |
|---|---|
| ComfyUI 本体 | `C:\AI\ComfyUI_windows_portable` に入る（NVIDIA用のポータブル版） |
| モデル | WAI-Illustrious v17（メイン）、ControlNet 4種類（落書き・線画・奥行き・骨格）、顔の自動検出 |
| 追加の部品 | ControlNet の前処理（写真から骨格や奥行きを取り出す）、Impact Pack（顔の描き直し）、MangaScreen（トーン処理） |
| ワークフロー | 「コマのラフからキャラを描く」「トーン処理（MangaScreen-Lite）」 |
| ツール | コマ切り出し、コマはめ込み、コマ表（Excel） |
| 希望したときだけ | MOSS-Image ＋ マンガ透明素材LoRA（背景が透明なキャラ・擬音・効果線を作る。約17GB増える） |

全部で約25GB（MOSS も入れると約42GB）をダウンロードします。Cドライブに35GB以上（MOSS ありなら55GB以上）の空きが必要です。

## 入れ方（最初の1回）

1. GitHub のこのリポジトリのページで「Code」→「Download ZIP」を押してダウンロードする
2. ダウンロードした zip を右クリック →「プロパティ」→ 下のほうの「許可する」にチェック →「OK」
   （これをしないと、実行のたびに警告が出ます）
3. zip を展開して、`manga` フォルダの中の **`setup.bat`** をダブルクリックする
   - 「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」
   - 「MOSS-Image も入れますか？」と聞かれたら、`y`（入れる）か、そのまま Enter（入れない）
   - Git や 7-Zip を入れるときに「このアプリがデバイスに変更を加えることを許可しますか？」と出たら「はい」
4. 「すべて完了しました」と出たら終わりです。デスクトップに次の3つができます。
   - **ComfyUI（マンガ）** … ComfyUI を起動する（ブラウザで開く）
   - **コマ切り出し** … ネーム画像をここにドラッグ＆ドロップ
   - **コマはめ込み** … ネーム画像をここにドラッグ＆ドロップ

途中で止まったり失敗したりしても、もう一度 `setup.bat` を実行すれば、終わっていない部分だけやり直します（ダウンロードは続きから再開します）。記録は `manga\install_log.txt` に残ります。

> **このzipを展開したフォルダは消さないでください。** コマ切り出し・はめ込みのツールはこのフォルダの中にあります。

## 使い方

### ① ネームを描く

- コマとコマの間には**白いすき間**を空ける（すき間がないと1つのコマとしてつながってしまう）
- コマの枠線は**閉じた形**で描く（紙の端まで出るコマ＝タチキリは大丈夫です）
- ラフは棒人間で十分。人物の横に「A」「B」などキャラの名前を書いておくと③で迷わない
- 画像の名前はページ番号にする（`p1.png`、`p2.png` …）。CLIP STUDIO なら「画像を統合して書き出し」で PNG に

### ② コマ切り出し

デスクトップの「コマ切り出し」に、ネーム画像（複数でもよい）をドラッグ＆ドロップします。
ネーム画像の横に `p1_コマ` フォルダができます。

| できるもの | 内容 |
|---|---|
| `p1_c01.png`, `p1_c02.png` … | コマごとのラフ（枠線は消してある）。ComfyUI の画像一覧にも自動で入る |
| `確認用.png` | どこをコマと判定したかを番号付きで表示。**まずこれを開いて、番号の順番を確認** |
| `採用` フォルダ | ③で選んだ画像を入れる場所 |

コマの番号は、日本のマンガの読み順（右上から左へ、上から下へ）で付きます。
最初の1回はお試し用のネーム `manga\sample\p1.png` を切り出してあります。

### ③ ComfyUI で描く

1. 「ComfyUI（マンガ）」で起動し、左の「ワークフロー」から **「コマのラフからキャラを描く」** を開く
2. 「コマのラフ」で `p1_c01.png` などを選ぶ
3. 「指示文」に、コマ表の指示文を貼る
4. キャラのLoRAを作ったら、「キャラA の LoRA」を選んで **Ctrl+B** でオンにし、ファイル名を選ぶ
   （最初はオフになっています。LoRAがなくても、指示文だけで描けます）
5. 「保存名」をコマに合わせる（例: `manga/p1_c03`）
6. 右上の「Run（実行）」→ `C:\AI\ComfyUI_windows_portable\ComfyUI\output\manga` に4枚保存される
7. 気に入った1枚を、`p1_コマ\採用` フォルダにコピーする（名前は変えなくてよい）

| うまくいかないとき | 変えるところ |
|---|---|
| ラフの構図どおりにならない | 「ラフの効き具合」の strength を上げる（〜0.8） |
| キャラの顔が崩れる・似ない | 同じ所の end_percent を下げる（0.5〜0.6） |
| ラフをそのまま下絵にしたい | 「描く」の denoise を 0.6〜0.7 に下げる |
| 2人のコマで特徴が混ざる | LoRAを両方 0.5 にして描き、あとで1人ずつ描き直す |

### ④ コマはめ込み

デスクトップの「コマはめ込み」に、ネーム画像（`p1.png`）をドラッグ＆ドロップします。
`採用` に入れた画像がコマの形に合わせてはめ込まれ、`p1_仮組み.png` ができます。
まだ描いていないコマはラフのまま残るので、途中経過の確認にも使えます。

### コマ表（`コマ表.xlsx`）

- 「キャラ」シートに、キャラの名前・呼び出し名・見た目の特徴・LoRAのファイル名を書く
- 「コマ表」シートに、ページ・コマ・出るキャラ・表情・場所を書くと、**指示文・保存名・使うLoRA** が自動でできる
- 黄色い列が入力するところ、緑の列が自動でできるところです

## 注意

- 他の人の作品（アニメ・マンガのスクリーンショットなど）を写真の構図の見本に使うのは、自分で楽しむ範囲にとどめてください。公開するなら、自分で撮った写真か素材サイトの画像を使ってください。
- モデルにはそれぞれ利用条件があります（WAI-Illustrious と ControlNet は Fair AI Public License、MOSS-Image 関連は Apache-2.0）。
- キャラ専用のLoRAを作るソフト（kohya_ss、OneTrainer）は、このセットには入っていません。

