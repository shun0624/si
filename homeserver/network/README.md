# ネットワーク（家じゅうの配線・スイッチ・Wi-Fi）

## 必要な配線の本数

| つなぐもの | か所 | 1か所の本数 | 本数 | 電気もLANで送る（PoE） |
|---|---|---|---|---|
| 部屋の情報コンセント | 6〜8 | 2口 | 12〜16 | なし |
| 監視カメラ | 6 | 1 | 6 | **あり**（1台 5〜13W） |
| インターホン（玄関） | 1 | 1〜2 | 1〜2 | 機種による |
| Wi-Fi アクセスポイント（天井） | 2 | 1 | 2 | **あり** |
| 予備（太陽光・給湯器・換気・EV・TV裏など） | — | — | 4 | — |
| **合計** | | | **約25〜30本** | |

- 部屋は **1か所2口** がおすすめ。後から足すのは壁を開けるので大変、先に入れておくのが安い。
- 全部をスイッチにつなぐ必要はありません。**パッチパネルには全部つなぎ、スイッチには使う所だけつなぐ**。

## ラック側の機器

| 機器 | おすすめ | 理由 |
|---|---|---|
| パッチパネル | 19インチ 24口 × 2（例: StarTech C6PANELUTP241U、約3,100円） | 30本＋予備が入る |
| スイッチ | PoE+ 24口＋10G(SFP+) 4口の管理型（例: TP-Link SG3428XMP） | カメラ・Wi-Fi に電気を送れる。NAS を10Gでつなげる。VLAN（下記）が使える |
| ルーター | VLAN 対応のもの（スイッチと同じ TP-Link Omada の ER シリーズなど） | プロバイダ支給のルーターは VLAN 非対応が多い |
| Wi-Fi | 天井付けの PoE アクセスポイント 2台（平屋25坪程度なら2台で足りる） | 電源工事が不要、見た目もすっきり |

## ネットワークを分ける（VLAN）

1本の線・1台のスイッチの中で、ネットワークを用途ごとに区切ります。

| 区分 | つなぐもの | ルール |
|---|---|---|
| 家族用 | PC・スマホ・NAS | ふつうに使う |
| カメラ用 | 監視カメラ・インターホン | **インターネットに出さない**（カメラの乗っ取り対策）。HA と NAS だけが見られる |
| 家電用（IoT） | エアコン・照明・給湯器など | インターネットには出られるが、家族用には入れない |
| お客さん用 | 来客の Wi-Fi | インターネットだけ |

## 配線のルール

- ケーブルは **Cat6A**（10Gまで対応）。屋外のカメラ用は **屋外用（UV対策）** を使う。
- 壁の中の線は、パッチパネル裏で **パンチダウン式キーストーンジャック** に付ける。
- 番号の付け方（例）: `R1-1`＝部屋1の1口目、`C1`〜`C6`＝カメラ、`AP1`・`AP2`＝Wi-Fi、`D1`＝玄関インターホン。壁側とパッチパネル側に同じ番号を貼る。

## インターホンについて

- 一般的なドアホン（パナソニックなど）は、玄関子機と室内親機を **専用の線** でつなぎ、親機が Wi-Fi でスマホにつながる仕組み。HA から細かく操作するのは苦手。
- HA に直接取り込みたいなら、**PoE のカメラ付きドアベル**（IP型）が向いている。
- どちらにしても、**玄関子機の位置にLANを1本入れておく**（あとから IP 型に替えられる）。

## 工務店に伝えること

設計段階で決めないと、あとからは難しいことです。

- [ ] ラック置き場（1畳程度の収納・納戸）。床置きで 60〜80kg
- [ ] 置き場に **専用回路 20A のコンセント**（2口以上）
- [ ] 置き場の **換気**（換気扇かガラリ）。ふだん約300Wの熱が出る
- [ ] 光回線の引き込み（ONU）をラック置き場に
- [ ] 各部屋の情報コンセント 6〜8か所 × LAN 2本（Cat6A）
- [ ] 監視カメラ 6か所に LAN 1本＋屋外防水ボックス
- [ ] 玄関インターホン位置に LAN 1本（専用線とは別に）
- [ ] 天井 Wi-Fi 2か所に LAN 1本
- [ ] すべての配線に **空配管（CD管／PF管）** を付けてもらう（将来の入れ替え用）
- [ ] 離れ（コンテナ）にも配管＋LAN 2本（離れ側は10インチラックの中継点）
- [ ] 壁側・ラック側の両方に番号ラベル
