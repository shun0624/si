## 通帳から仕訳を作るスキル（bank-journal）

預金通帳のコピーと、その会社の過去の総勘定元帳をClaudeに貼り付けると、銀行取引の仕訳をExcelで出力するClaude用のスキルです。

- 過去の元帳から、相手先ごとの科目・補助科目・税区分を自動で当てはめます
- 摘要の表記が違う取引（漢字とカナなど）は、JEV（TypeSafe AI）で高速に判定します
- 借入返済は、過去の返済履歴から元本と利息に分けます（推定）
- 振込手数料が引落額に含まれている相手先は、過去の仕訳から判断して分けます（推定）
- 通帳の残高と計算が合うかを確認し、読み取りミスを見つけます
- **分からないものは「不明」と表示します**（推測で埋めません）

### 入れ方（Claudeのアプリ／claude.ai）

1. このリポジトリの `release/bank-journal.zip` をダウンロードする
2. Claudeの「設定」→「機能（Capabilities）」→「スキル」で、zipをアップロードする
3. 「コード実行とファイル作成」をオンにする

### 使い方

チャットに元帳と通帳を貼り付けて、次のように頼みます。

> 通帳から仕訳を切って。預金は普通預金／〇〇銀行。

Excelには次のシートが入ります。

| シート | 内容 |
|---|---|
| 仕訳 | 判定ごとに色分け（緑＝JEV判定、黄＝推定、橙＝要確認、赤＝不明） |
| 集計 | 件数、残高チェックの結果、JEVの使用状況 |
| 通帳読取 | 通帳から読み取った内容（原本との照合用） |
| ルール表 | 元帳から作った仕訳パターン |

### JEVを使うための設定

JEVは TypeSafe AI の判定専用AIです（2026年10月時点では先行利用で、申込みが必要です）。APIキーがなくてもスキルは動きますが、その場合は表記が違う取引の多くが「不明」になります。

APIキーの渡し方は2つあります。

- **毎回チャットで渡す**：「JEVのAPIキーは ○○」と書く。手軽ですが、キーがチャットの履歴に残ります。
- **スキルに入れておく**：`skills/bank-journal/jev_config.json.example` を `jev_config.json` という名前でコピーし、キーを書き込んでから zip を作り直してアップロードする。

また、Claudeのコード実行環境から `api.typesafe.ai` に接続できる必要があります。接続できない場合は、設定のネットワーク許可（許可するドメイン）に `api.typesafe.ai` を追加してください。

### 注意

- お客様の通帳と元帳の内容が、Claudeと、JEVを使う場合はTypeSafe AIに送られます。事務所の情報管理のルールで問題ないか確認してから使ってください。
- 「推定」の行（借入金の利息、手数料込みの支払）は、返済予定表や振込明細で確かめてください。決算では、借入金の残高を残高証明書と合わせてください。
- 出力するのは確認用のExcelです。会計ソフトに取り込む形式（CSV）が必要な場合は、ソフト名を教えてもらえれば追加します。
