# ホームサーバー 全体計画

新築の家に、次の3つをまとめて作るための計画です。

| 作るもの | 中身 | 詳しくは |
|---|---|---|
| NAS（ファイル置き場） | 3.5インチHDDを **16台以上** 入れられる箱。写真・書類・カメラの録画の保存先 | [nas/](nas/) |
| HA サーバー（家の自動化） | Home Assistant を動かす小型PC。照明・エアコン・センサー・監視カメラ・インターホンをまとめる | [ha/](ha/) |
| ネットワーク | 家じゅうのLAN配線・スイッチ・Wi-Fi・監視カメラ6台・インターホン・各部屋の情報コンセント | [network/](network/) |

> 「HA」は Home Assistant（家の自動化ソフト）として計画しています。

---

## 1. いちばん大事な結論：10インチか19インチか

**NAS は10インチラックには入りません。** NAS は19インチラック（またはタワー型ケース）で作ります。

理由:

- 3.5インチHDDは1台で 幅 約102mm × 長さ 約147mm × 厚さ 約26mm。
- 10インチラックの内側の幅は 約220mm。HDDを立てて並べても1列 **7台** が限界で、16台入れるには3段（約9U）必要になる。
- 10インチラックは奥行きも浅い（例: DeskPi RackMate T2 は奥行き 約26cm）。HDDの後ろにマザーボード・電源・ファンを置く場所がない。
- 16台のHDDは電源を入れた瞬間に合計 約400W 流れる。10インチ用の小さな電源では足りない。

19インチなら、4U（高さ約18cm）の箱1つに16〜20台入る市販品があります（例: SilverStone RM43-320-RS、20台。楽天で 約12.5万円・2026年11月時点）。

### 3つの案

| 案 | 中身 | 良いところ | 気になるところ |
|---|---|---|---|
| **A. 19インチ1台にまとめる（おすすめ）** | 19インチの床置きラック（15〜18U）に NAS・HA・スイッチ・ルーター・UPS を全部入れる | 置き場所が1か所。配線が短い。停電対策（UPS）も1台で済む | ラックが大きい（幅60cm×奥行き60〜80cm）。置き場所を設計段階で確保する必要 |
| B. 10インチ＋NAS別置き | 10インチ（12U）に HA・スイッチ・ルーター・パッチパネル。NAS は横に19インチ4Uかタワー型 | 10インチ部分は小さく見た目がすっきり。作ったパッチパネルが使える | 箱が2つになる。UPSも2台か、配線が増える |
| C. 全部10インチ | — | — | **NASが入らないので不可** |

**おすすめは A。** NAS が19インチ（または大きなタワー）になる時点で、HA やスイッチを別の10インチに分けても箱が増えるだけだからです。

10インチは、**離れ（コンテナ）やテレビ裏などの「小さな中継点」** に使うと活きます（10口パッチパネル＋小型スイッチ＋Wi-Fi）。

## 2. 置き場所と大きさ（案A）

### ラックの中身（下から順に。重い物ほど下）

| 段 | 高さ | 中身 |
|---|---|---|
| 最下段 | 2U | UPS（停電対策のバッテリー。1500VA 程度） |
| | 4U | NAS 本体（16〜20ベイ） |
| | 1U | 空き（NASの熱逃がし） |
| | 1U | 棚：HAサーバー（小型PC）・Zigbee 機器など |
| | 1U | 棚：ONU（光回線の箱）・ルーター |
| | 1U | PoE スイッチ（24口＋10G×4） |
| | 1U | ケーブル整理パネル |
| 最上段 | 2U | パッチパネル 24口×2（部屋・カメラからの配線が全部ここに来る） |
| | 3〜5U | 予備（AIサーバー機の棚、増設用） |
| **合計** | **15〜18U** | |

### ラックの大きさ

- 高さ: 15〜18U の床置きキャビネット（外寸の高さ 約80〜100cm）
- 幅: 約60cm、奥行き: **60cm以上（できれば80cm）**
  - 4UのNASケースは奥行き 50〜65cm のものが多い（買う前に必ず確認）。
  - 楽天で「19インチ 15U」と検索すると出てくる安い壁掛け型（奥行き 約30cm）は **NAS が入らない** ので選ばない。
- 重さ: 全部入れると 60〜80kg 程度。キャスター付きの床置き型にする。
- 前後に作業スペース（前60cm・後ろ40cm程度）が必要 → **1畳くらいの収納・納戸** があると理想。

## 3. 電気・熱・音

| 機器 | ふだんの消費電力（目安） |
|---|---|
| NAS（HDD16台が回っている時） | 150〜200W（起動の瞬間は約400W） |
| PoE スイッチ＋カメラ6台＋Wi-Fi | 70〜100W |
| HA サーバー | 10〜15W |
| ONU・ルーター | 15〜20W |
| **合計** | **約250〜330W** |

- 電気代の目安: 約280W × 24時間 × 365日 ≒ 2,450kWh → **年 約7.6万円**（31円/kWh）。
  HDDを使わない時に止める設定（スピンダウン）や、最初は8台で始めると下がります。
- 熱: 小さな電気ストーブを1日中つけているのと同じ。高気密高断熱の家で閉じた収納に置くと熱がこもるので、**換気扇かガラリ（通気口）を付ける**。澄家（換気システム）との関係は工務店に相談。
- 音: HDD16台とファンはそれなりに音が出る。寝室の隣は避ける。
- コンセント: **専用回路（20A）を1つ** 用意してもらう。

## 4. 進め方（いつ・何をするか）

| 段階 | 時期 | やること |
|---|---|---|
| 0 | **設計中（今）** | ラック置き場所（1畳）・専用コンセント・換気・配管を工務店に伝える。→ [network/README.md の「工務店に伝えること」](network/README.md#工務店に伝えること) |
| 1 | 建築中 | LAN配線（Cat6A）と空配管。部屋ごとに番号札（ラベル）を付けてもらう |
| 2 | 入居時 | ラック・パッチパネル・スイッチ・ルーター・Wi-Fi・UPS を設置。家の中のネットがまず動く状態に |
| 3 | 入居後すぐ | HA サーバー・監視カメラ6台・インターホン連携 |
| 4 | その後 | NAS（HDDは8台から）。HAやPCのバックアップ先を NAS に |
| 5 | 必要になったら | HDDを16台まで増設、AIサーバー機をラックへ |
