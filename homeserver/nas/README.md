# NAS（16ベイ以上の3.5インチHDD）

家族の写真・書類・PCのバックアップ・監視カメラの録画を保存する、自作のファイルサーバーです。

## 条件

- 3.5インチHDDを **16台以上** 入れられる
- 19インチラック 4U（10インチには入らない。理由は [PLAN.md](../PLAN.md#1-いちばん大事な結論10インチか19インチか)）
- 最初は HDD 8台で始めて、あとから増やせる
- 家のネットワークに 10G でつなぐ

## 中身の部品

| 部品 | 選び方 | 理由 |
|---|---|---|
| マザーボード・CPU | ATX。Intel Core i3〜i5（動画の変換が得意）か、ECCメモリ対応のもの | 動画再生（Jellyfin など）とファイル保存の両方に足りる |
| メモリ | 32GB 以上（できれば ECC） | 保存の仕組み（ZFS）がメモリを使う |
| HDDをつなぐカード（HBA） | LSI 9300-16i など（IT モード） | マザーボードだけでは16台つなげない。熱くなるので風を当てる |
| 電源 | 750W・80PLUS Gold 以上 | HDD 16台の起動時に 約400W 必要 |
| 起動用SSD・アプリ用 NVMe SSD | 250GB〜1TB | OSとアプリを HDD と分ける |
| 10G ネットワークカード | SFP+（Intel X710 など） | スイッチの 10G 口につなぐ |

## ソフト（OS）

| | TrueNAS SCALE | Unraid |
|---|---|---|
| 値段 | 無料 | 有料（買い切りあり） |
| HDDの増やし方 | 同じ容量のHDDをまとめて増やすのが基本 | 違う容量のHDDを1台ずつ足せる |
| データの守り方 | とても強い（ZFS） | ふつう |
| 向いている使い方 | 最初に8台そろえて、次に8台足す | 少しずつ買い足したい |

**おすすめ: TrueNAS SCALE。** 16TB を 8台 × 2組 で考えると分かりやすいです。

## 容量の目安

- 8台 × 16TB、2台まで壊れても大丈夫な組み方（RAIDZ2）→ 使える容量 約 **96TB**
- 8台をもう1組足すと → 約 **192TB**

監視カメラの録画:

- 6台 × 約4Mbps（400万画素・H.265）＝ 1日 約 **260GB**
- 30日分残すと 約 **7.8TB**
- 録画は書き込みが止まらないので、写真・書類とは別の保存場所（録画専用の区画か、録画用HDD 2台）にする

## バックアップ（大事）

NAS は「壊れにくい」だけで、バックアップではありません。

- 大切なデータは **もう1か所**（外付けHDD・離れに置く小さな NAS・クラウドなど）にもコピーする。
- 事務所・顧問先のデータを置く場合は、事務所の規程に合わせて扱う（外部のクラウドに出してよいか確認）。
